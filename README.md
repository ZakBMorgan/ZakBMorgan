### 🚀 Featured Projects

**[GymCast](https://github.com/ZakBMorgan/gym_predictor)** — ML-powered gym occupancy forecasting
Built a leak-resistant, multi-horizon ML pipeline that collects and transforms public occupancy data into rolling 24-hour traffic forecasts. Validated with walk-forward testing against four baselines and served through a Flask prediction API, with tests verifying feature timing and train-serve consistency.
`Python` `pandas` `LightGBM` `scikit-learn` `Flask`

**[Findly](https://github.com/qutch/findly)** — AI-powered local file search (HackBeanpot)
Built the file-watching and ingestion subsystem (TypeScript + Chokidar) detecting filesystem changes and queueing documents for indexing with up to 3 concurrent processing requests. Contributed to Electron integration linking the desktop client to backend services, and collaborated on the AI search pipeline — OpenAI embeddings, Pinecone vector search, and Gemini-based reranking/summarization.
`TypeScript` `Electron` `Python` `FastAPI` `Pinecone` `OpenAI API` `Gemini`

**CookYourBooks** — Modular recipe management app *(private repo — Northeastern CS 3100 team project)*
Designed a modular Java service architecture separating domain, persistence, and presentation layers, supporting both JavaFX and a 17-command CLI. Built recipe scaling, unit conversion, shopping-list aggregation, and JSON persistence with immutable domain transformations. Owned Search & Filter using MVVM with 300ms debounced async search, task cancellation, and FX-thread-safe UI updates.
`Java` `JavaFX` `Jackson` `JUnit` `Mockito` `Gradle`
